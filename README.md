# 🌟 Hệ Thống Xét Học Bổng Pro DUE (HBSTARS)

Hệ thống quản lý và xét duyệt học bổng Khuyến khích học tập (KKHT) chuyên nghiệp dành cho sinh viên DUE.

## 🚀 Tính năng chính
- **Nhập liệu thông minh:** Hỗ trợ nhập ngân sách theo Quỹ chung hoặc theo từng Ngành/Khóa từ file Excel.
- **Xét duyệt đa bước:** Tự động hóa quy trình xét duyệt qua 4 bước: Tài năng -> Vượt khó -> Quốc tế -> Học tập & Rèn luyện.
- **Quản lý ngân sách:** Tự động tính toán lũy kế, cảnh báo vượt quỹ và ưu tiên tối thiểu cho từng hệ đào tạo.
- **Báo cáo chuyên nghiệp:** Xuất file Excel tổng hợp 29 cột và các mẫu báo cáo hành chính (5-TN, 5-VK, 4-QT, 4-HTRL).

## 🛠 Hướng dẫn triển khai lên GitHub Pages
1. **Clone dự án:** `git clone https://github.com/diendue48k/HBSTARS.git`
2. **Đưa lên GitHub:**
   ```bash
   git add .
   git commit -m "Deploy scholarship system"
   git push origin main
   ```
3. **Cấu hình Pages:** Vào `Settings -> Pages` trên GitHub, chọn branch `main` và lưu lại.

## 📖 Hướng dẫn sử dụng
1. **Cấu hình:** Nhập mã học kỳ (ví dụ: 252).
2. **Nhập liệu:** Tải tệp mẫu và điền dữ liệu ngân sách + danh sách sinh viên.
3. **Kiểm tra:** Rà soát dữ liệu sinh viên (GPA, DRL, Diện khó khăn...).
4. **Xét duyệt:** Nhấn "Bắt đầu chạy" để hệ thống tự động phân bổ học bổng.
5. **Kết quả:** Xem nhanh kết quả trực tuyến và tải về bộ báo cáo Excel đầy đủ.
